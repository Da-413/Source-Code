# 기업 가치 평가 & 금융 데이터 마이닝

FnGuide의 상장기업 재무 데이터를 자동으로 수집하고, 여러 회귀 방법을 비교해 **시가총액과 재무지표의 관계**를 분석한 프로젝트입니다.

## 한눈에 보기

| 항목 | 내용 |
|---|---|
| 데이터 | 상장기업 301개사 재무 데이터 |
| 수집 | Selenium 기반 동적 크롤링 |
| 분석 | 선형 · 다항 · LOESS · Ridge · Lasso 회귀 |
| 주요 결과 | 선형 회귀 R² **0.775** |
| 주요 기술 | Python, Selenium, Pandas, R |

## 분석 흐름

```text
FnGuide
   ↓

   ↓

   ↓

   ↓
여러 회귀 모델 비교
   ↓
모델 평가 · 해석
```

## 1. 데이터 수집

정적 HTML 요청만으로는 필요한 데이터를 안정적으로 수집하기 어려워 Selenium을 사용했습니다. 기업별 페이지를 순회하며 재무 데이터를 수집하고 Pandas DataFrame으로 정리했습니다.

수집 이후에는 결측치와 문자열을 정리하고 분석 가능한 숫자형 데이터로 변환했습니다.

## 2. 모델링

하나의 회귀 모델만 사용하는 대신 서로 다른 특성을 가진 모델을 비교했습니다.

| 모델 | 목적 |
|---|---|
| Linear Regression | 기본적인 선형 관계와 변수 영향 확인 |
| Polynomial Regression | 비선형 관계 반영 |
| LOESS | 국소적인 비선형 패턴 확인 |
| Ridge | 다중공선성이 있는 변수의 계수 안정화 |
| Lasso | 규제와 변수 선택 효과 확인 |

### 선형 회귀

전체 변수에서 유의미한 변수를 선택해 모델을 단순화했고, 최종 선형 회귀에서 **R² 0.775**를 확인했습니다.

주요 변수로는 RIM 기업가치, 매출액증가율, 부채비율, 매출총이익률, ROA, ROI, 총자산회전율 등이 선택됐습니다.

### 비선형 모델

Polynomial Regression은 변수별 차수를 탐색하고 BIC를 기준으로 후보 모델을 비교했습니다. LOESS는 여러 span을 교차검증해 비선형 관계를 확인했습니다.

### Ridge / Lasso

재무 변수 사이의 높은 상관관계로 회귀계수가 불안정해질 수 있어 Ridge와 Lasso를 추가로 비교했습니다. `cv.glmnet()`을 이용해 λ를 선택하고 규제 적용 전후의 결과를 확인했습니다.

## 3. 모델 평가

단일 train/test split 결과에만 의존하지 않도록 반복 샘플링과 RMSE·MAPE를 이용해 모델을 비교했습니다.

분석 과정에서 모델의 성능뿐 아니라 **설명력과 해석 가능성**도 함께 고려했습니다. 복잡한 모델이 항상 더 적합한 것은 아니기 때문에 선형 모델과 비선형 모델의 차이를 함께 확인했습니다.

## 4. 크롤링 자동화

301개 기업을 반복해서 수집해야 했기 때문에 수작업 대신 크롤링 과정을 자동화했습니다. 동적 페이지 로딩 과정에서 발생하는 누락을 줄이기 위해 페이지 로딩을 기다린 뒤 데이터를 읽도록 구성했습니다.

관련 구현은 `src/crawler.py`와 분석 노트북에서 확인할 수 있습니다.
